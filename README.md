# Student Social Media Addiction Analysis

## Project Overview
This project analyzes student social media usage and its impact on academic performance, sleep, mental health, and addiction levels.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
The dataset contains information about students, including:
- Age
- Gender
- Academic Level
- Daily Social Media Usage
- Most Used Platform
- Sleep Hours
- Mental Health Score
- Addicted Score

## Project Steps
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Finding Insights

## Key Analysis
- Most used social media platform
- Relationship between screen time and sleep
- Social media usage and academic performance
- Relationship between sleep and addiction
- Top addicted users

## Conclusion
The analysis helps understand how social media usage can affect students' academic performance, sleep, mental health, and addiction levels.
