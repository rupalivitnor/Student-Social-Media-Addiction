# 📊 Student Social Media Dashboard

An interactive **Student Social Media Analytics Dashboard** built to analyze students' social media usage and understand its impact on academic performance, sleep, and other student-related factors.

## 📌 Project Overview

This project provides an interactive dashboard for exploring student social media behavior and identifying meaningful patterns in the data.

The dashboard focuses on:

* Social media usage patterns
* Academic performance impact
* Sleep and social media usage
* Student-level insights
* Platform usage analysis
* Overall student analytics

## 🛠️ Technologies Used

* **React**
* **TypeScript**
* **TanStack Start**
* **Tailwind CSS**
* **Vite**
* **JavaScript**
* **Data Visualization**

## 📈 Dashboard Features

### 👨‍🎓 Student Analysis

* View student-level information
* Explore student demographics
* Analyze student behavior patterns

### 📱 Social Media Usage

* Average daily social media usage
* Most-used social media platforms
* Usage patterns across students

### 📚 Academic Impact

* Analyze the relationship between social media usage and academic performance
* Identify academic impact patterns

### 😴 Health & Lifestyle

* Analyze sleep hours
* Explore relationships between social media usage and sleep
* Examine student lifestyle patterns

### 📊 Interactive Analytics

* Interactive dashboard
* Multiple analytical sections
* Easy-to-understand visualizations
* Data-driven insights

## ▶️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/rupalivitnor/student-social-media-dashboard.git
```

### 2. Open the project

```bash
cd student-social-media-dashboard
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the local application

Open the local URL shown in your terminal, usually:

```text
http://localhost:5173
```
